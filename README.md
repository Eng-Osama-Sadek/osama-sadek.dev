# Osama Sadek — Portfolio

Premium developer portfolio for Osama Sadek — AI Maker & Automation Architect. Built with Next.js 14, TypeScript, Tailwind, Framer Motion, and Resend.

## Stack
- Next.js 14 (App Router) + TypeScript (strict)
- Tailwind CSS + custom design tokens
- Framer Motion + Lenis smooth scroll
- React Hook Form + Zod
- Resend (contact form emails)
- Deployed on Vercel

## Local Setup
```bash
npm install
cp .env.example .env.local
npm run dev
