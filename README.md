# Osama Sadek — Portfolio 🚀

A premium, high-performance personal portfolio built to showcase my work as an **AI Maker & Full-Stack Automation Engineer**.

🌍 **Live Site:** [osama-sadek-dev.vercel.app](https://osama-sadek-dev.vercel.app)

## ✨ Features
- **Ultra-Premium Design:** Deep animated blue gradient, glassmorphism cards.
- **Advanced Motion:** Smooth scroll, magnetic buttons, 3D tilt cards.
- **Fully Responsive:** Stunning on all devices.
- **Project Showcase:** Filterable grid with detailed pages.
- **Contact Form:** React Hook Form + Zod + Resend.

## 🛠 Tech Stack
- Next.js 14 (App Router), TypeScript, Tailwind CSS
- Framer Motion, Lenis, React Hook Form, Zod, Resend
